# BMAX Quad Menu v1.1.0

3ds Max style quad menus for Blender · Blender 3ds Max 風格四象限選單

- Documentation / 說明: https://github.com/Aomay77/BMAX-Quad-Menu
- Nothing is enabled after install. Open Preferences → Add-ons → BMAX Quad Menu → Quad Sets, pick a set, press ⏺ Record and press your shortcut.
- 安裝後預設不啟動。到 Preferences → Add-ons → BMAX Quad Menu → Quad Sets，選一組 → 按 ⏺ Record → 按下你的快捷鍵即啟用。
